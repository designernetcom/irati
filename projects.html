robotics installation

From robot installation to production

How a WO robot cell goes from a drawing to a running line — we build the full trial at our premises so the customer requirement is covered before dispatch.

  1. 01 [ step ]

    Planning

    Understanding the application, cycle time and layout before anything is ordered or moved.

  2. 02 [ step ]

    Installation

    Mechanical installation of the robot, controller and cell hardware at your site.

  3. 03 [ step ]

    Configuration

    Controller configuration, I/O mapping and end-effector setup for your process.

  4. 04 [ step ]

    Calibration

    Mastering, tool frames and user frames set so positions are accurate and repeatable.

  5. 05 [ step ]

    Programming

    Motion, logic and I/O programming written for the actual production sequence.

  6. 06 [ step ]

    Testing

    Full trial runs — we build the complete trial at our premises before dispatch.

  7. 07 [ step ]

    Integration

    Integration with the surrounding line and handover, with your staff trained on the cell.
